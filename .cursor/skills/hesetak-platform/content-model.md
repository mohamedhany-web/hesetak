# Content model — مناهج · كورسات · اختبارات · LMS

## مسار المناهج الدراسية الرسمية

محتوى يواكب ما يدرسه الطالب في مدرسته/جامعته — روضة → جامعة.

### أنواع المنهج

| نوع | ملاحظة |
|-----|--------|
| سعودي | الأكثر طلبًا — افتراضي إن لم يُحدَّد غيره |
| قطري | وزارة التعليم والتعليم العالي |
| بحريني | وزارة التربية |
| إماراتي | مع ملاحظة مناهج دولية موازية في بعض المدارس الخاصة |
| كويتي | وزارة التربية |

- فلتر بحث ثلاثي: **مرحلة + مادة + نوع منهج**  
- ملف المعلم يحدد أنواع المناهج المعتمدة؛ اعتماد نوع جديد = مراجعة أكاديمية مستقلة  
- بنية: منهج → وحدات → دروس (فيديو مسجّل أو حصة حيّة مجدولة)  
- الجامعة: لا صف دراسي ثابت — بحث بالمقرر مباشرة  

**خارج مسار المناهج:** محتوى بلا منهج وطني → مسار الكورسات.

## مسار الكورسات المستقلة

مستقل عن منهج مدرسة: مهارات، تحضير اختبارات، تحفيظ قرآن، لغات عامة، دورات لأولياء الأمور، تطوير مهني للمعلمين.

| | مناهج | كورسات |
|--|-------|--------|
| الارتباط | منهج وطني + مرحلة | مستقل |
| الجمهور | طالب مدرسة/جامعة | أي متعلم (طالب/ولي/معلم) |
| أمثلة | رياضيات خامس سعودي | قدرات، قرآن، إنجليزي عام |

ميزات الكورس: وحدات/دروس، مجتمع أسئلة للمشتركين، شهادة إتمام، معاينة مجانية لدرس واحد على الأقل.  
معلّم منتج محتوى: تصنيف توظيف منفصل + مراجعة اعتماد قبل النشر.

## الاختبارات والتقييم (AI = دعم قرار)

1. **اختبار مستوى صوتي** — محادثة، تحليل فوري، يخزَّن في ملف الطالب ويغذّي التوصيات  
2. **اختبار كتابي** — لبعض المواد غير اللغوية (رياضيات/علوم)  
3. **توليد أسئلة من الدرس** — من التفريغ النصي فقط؛ حالة `pending_review` حتى يعتمد المعلم  
4. **تكيّفي (IRT)** — سؤال حسب الأداء السابق  
5. بنك أسئلة + حد زمني + تصحيح موضوعي فوري  
6. إجابات حرة: AI يقترح درجة؛ **لا تدخل السجل الرسمي تلقائيًا** في الإصدار الأول؛ عيّنة عشوائية لمراجعة بشرية  

حقول مفيدة: `lesson_transcript`, `generated_by_ai`, `pending_review|approved|rejected`, `ai_score`, `human_override`.

## LMS (مختصر)

- مساعد درس: يجيب من نص الدرس فقط؛ وضع اقتراح ثم تلقائي؛ تصعيد للمعلم عند ضعف الثقة  
- تلخيص ونقاط مفتاحية بعد رفع فيديو (مراجعة معلم)  
- توصيات (تعاوني + محتوى) من اختبارات + نمط مشاهدة  
- رصد تسرّب → إشعار طالب/ولي  
- تقرير تقدّم ذكي لولي الأمر من ملاحظات المعلم + بيانات الاختبار/المشاهدة  
- **جديد:** واجبات + تسليم + تصحيح؛ حماية تنزيل/علامة مائية  
- **جديد:** دفتر درجات موزون لكل منهج/كورس  
- **جديد:** تقييم دوري للمعلم عن الطالب (يغذّي التقرير الذكي)
