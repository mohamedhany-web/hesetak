# Exclude — ميزات مرجعية (لا تُبنى)

من الدليل v3.0 الجزء الثامن + أي بند معلّم **مرجعي**.

> حصتك اليوم منصة أونلاين فردية بلا فروع. هذه الأقسام مرجع فقط إن توسّعت لاحقًا بقرار صريح.

## ممنوع في النطاق الحالي

| قسم | ماذا | يُفعَّل فقط إذا… |
|-----|------|------------------|
| 23 | إدارة الفروع والمراكز الفعلية | فتح مركز تدريبي فعلي |
| 24 | الموارد البشرية (موظفين برواتب) | فريق داخلي كبير يحتاج HR — المعلمون شركاء بعمولة لا موظفين هنا |
| 25 | الحضور والفصول الجماعية / قوائم انتظار مجموعات | إطلاق «دروس جماعية مخفّضة» كمنتج |
| 26 | الأنشطة اللامنهجية (نوادي، مسابقات) | فعاليات مجتمعية فوق الفردي |
| 27 | إدارة المخزون (كتب/منتجات) | بيع مواد فعلية |
| 28 | قاعدة معرفة داخلية (ويكي موظفين) | توثيق تشغيل داخلي منفصل عن كورسات الطلاب |

## أدوار مرجعية

- مدير فرع ونطاق بيانات لكل فرع  
- أي فصل مالي «لكل فرع»

## في خارطة الطريق

مرجع الدليل: «مرجعية — لا تُجدول الآن» لكل أقسام الجزء الثامن.

عند الشك: **لا تبنِ**. اسأل صاحب القرار.
