# Operations — مالية · CRM · توظيف/جودة · دردشة · شهادات · إشعارات · دفع · سياسات

## مالية

- طالب يدفع مقدمًا (باقة/محفظة) → مستحقات معلم شهرية بعد خصم عمولة قابلة للتعديل  
- سجل حركات دائم؛ التصحيح = حركة جديدة  
- مطابقة يومية مع بوابة الدفع؛ فروقات «تحتاج مراجعة»  
- ضريبة حسب دولة الطالب؛ محفظة أساسها **ريال سعودي** + تحويل عملات عند الشحن  
- **جديد:** كشف تكرار دفع/فاتورة مزدوجة → تعليق لمراجعة المحاسب  

## فواتير

كل دفع مكتمل يولّد فاتورة رسمية (أفراد، تجديد، شحن محفظة→فاتورة عند الاستهلاك، مؤسسية، إشعار دائن للاسترداد).  
رقم تسلسلي فريد، بنود، ضريبة، رابط تنزيل دائم.  
قرار معلّق: مستوى الفوترة الإلكترونية السعودية.

## CRM (داخل حصتك)

- قمعان: طالب محتمل + معلم مرشّح  
- أتمتة مراحل + واتساب + حقول مخصصة (مرحلة، منهج، نتيجة مستوى، باقة)  
- مراحل صريحة: مهتم → تم التواصل → اختبار محجوز → مسجّل / فاقد (مع من نفّذ ومتى)  
- **جديد:** أكواد خصم؛ إحالة (رصيد/خصم للطرفين)؛ كشف تكرار عميل؛ لوحات مندوب/مدير؛ تقرير قناة التحويل  

## جودة وإدارة

- مراقبة رسائل (أنماط تواصل خارجي) قبل البث  
- اقتراح معلمين عند تسجيل/تغيير معلم (مادة+مرحلة+منهج)  
- تقييم تراكمي للمعلم (اتجاه لا لحظة) + ملاحظات مشرف موزونة  
- كشف تكرار عند إضافة عميل/مرشّح  

## دردشة وامتثال (أولوية أمان)

فحص قبل الحفظ: جوالات خليجي/مصري، تمويه أرقام، إيميل، واتساب، منصات تواصل، عبارات «كلمني برة»…  
عند الاكتشاف: رفض + تسجيل مخالفة + تنبيه مشرف.  
عقوبات: تحذير → حظر مؤقت دردشة → حظر دائم + تصعيد.  
جداول: `chat_violations`, `chat_strikes`, `chat_whitelist_patterns`.  
إشعار سياسة عند أول دخول + checkbox.

## فصول افتراضية

رابط حصة تلقائي عند تأكيد الحجز؛ زر بدء قبل الموعد بـ 5 دقائق؛ واجهة تقرير فور انتهاء الحصة.

## شهادات

إصدار بكود تحقق؛ **جديد:** مصمم قوالب؛ صفحة تحقق عامة بلا تسجيل؛ إصدار جماعي.  
التوقيع التشفيري مؤجّل — بصري أولًا.

## إشعارات

داخلي · SMS OTP · واتساب (قوالب معتمدة) · بريد · دفع لاحقًا.

## مدفوعات

طبقة موحّدة: بطاقات عالمية، **مدى** (إلزامي للسعودية)، محافظ، تقسيط، تحويل بنكي.  
**القاعدة:** التأكيد النهائي من webhook البوابة فقط.

## سياسات آلية

| سياسة | سلوك |
|-------|------|
| إلغاء | مجاني حتى نافذة محددة؛ بعدها قواعد الغرامة |
| غياب معلم | استرداد/إعادة جدولة للطالب + غرامة من محفظة المعلم |
| اكتمال مالي | لا أجر بلا تقرير |
| قاصر | موافقة ولي أمر صريحة منفصلة |
