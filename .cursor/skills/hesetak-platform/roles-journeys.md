# Roles & journeys — حصتك v3.0

## Roles (in scope)

| دور | يملك |
|-----|------|
| زائر | تصفح الباقات/المناهج/الكورسات + ملفات معلمين معتمدين عامة |
| طالب / ولي أمر | حساب، محفظة، حجز، تسجيل مناهج/كورسات، رسائل، تقييم، شهادات، دعم/استرداد |
| ولي أمر (حساب رابط) | ربط عدة أبناء، متابعة كل ابن، فواتير وتجديد لكل الأبناء |
| معلم قيد المراجعة | تقديم، مستندات، مقابلة تقنية، متابعة حالة الطلب فقط |
| معلم معتمد | ملف، مواد/مناهج معتمدة، توافر، حجوزات، تقارير، رسائل طلاب، محفظة، توقف مؤقت |
| محاسب مالي | مستحقات، تسويات، فواتير، تقارير — بلا بيانات معلمين الشخصية/الرسائل |
| فريق التوظيف | قمع توظيف، مقابلات، مستندات، اعتماد/رفض |
| فريق علاقات عملاء | قمع عملاء محتملين + أتمتة |
| مشرف أكاديمي | مراجعة تسجيلات بنموذج موحّد، ملاحظات لملف المعلم، توصية إجراء |
| مدير عام | صلاحيات شاملة |

كل دور: لوحة مستقلة؛ لا يرى بيانات أدوار أخرى إلا ما يخصه. التحقق من الصلاحية عند التنفيذ.

## رحلة الطالب

1. تسجيل + تحديد مرحلة ونوع منهج (سعودي/قطري/بحريني/إماراتي/كويتي)  
2. اختيار مسار: حصص فردية و/أو منهج كامل و/أو كورس مستقل  
3. اختبار مستوى (صوتي AI و/أو كتابي لبعض المواد) — نتيجة تُخزَّن في الملف  
4. استكشاف معلمين معتمدين للمادة+المنهج؛ فيديو تعريفي؛ ترتيب بالتطابق  
5. اختيار معلم (يمكن التغيير لاحقًا بلا تكلفة)  
6. جدولة من توافر المعلم بتوقيت الطالب المحلي  
7. حضور الحصة → تقييم إلزامي للمعلم + الاطلاع على تقرير المعلم  
8. رسائل نصية محدودة بين الحصص (مراقبة آلية)  
9. أرشيف تقارير بلا حد زمني  
10. شهادات عند إتمام حصص/اختبار/منهج/كورس  

**لا تبنِ في الرحلة الحالية:** دروس جماعية مخفّضة (مرجعي).

## رحلة ولي الأمر

- جدول حصص كل ابن، تقارير المعلمين، حضور، تقدّم منهج/كورس  
- تجديد باقات + فواتير لكل ابن  
- موافقة صريحة على بيانات القاصر عند التسجيل (منفصلة عن الشروط العامة)

## رحلة المعلم (توظيف)

تقديم (شخصية، شهادة، دولة/منطقة زمنية، فيديو، مواد/مناهج)  
→ مراجعة أكاديمية  
→ مقابلة تقنية (كاميرا/مايك/نت)  
→ اعتماد + ضبط توافر + **تأهيل إلزامي** قبل أول حجز  

### AI في التوظيف (دعم قرار فقط)

- فرز جودة عيّنة فيديو (صوت/صورة)  
- مطابقة شهادة ↔ مادة/مرحلة  
- تحليل حصة تجريبية مسجّلة  
- بوت مرشحين (وضع اقتراح شهرًا على الأقل ثم تلقائي)  
- رصد انحدار تقييمات بعد الاعتماد → تنبيه جودة  

### بعد الاعتماد

- تقرير إلزامي فور انتهاء الحصة؛ الأجر لا يُضاف قبل التقرير  
- توقف مؤقت اختياري (لا يظهر لحجوزات جديدة؛ يحفظ التاريخ)  
- تقويم المعلم بتوقيته؛ الحجز يحوّل لتوقيت الطالب تلقائيًا  

### معايير جودة الحصة (تأهيل)

تفاعل، إدارة اللغة (إن وُجدت)، حضور مرئي، أدوات…  
عتاد المعلم مسؤوليته بالكامل (جهاز، كاميرا، مايك، نت).
