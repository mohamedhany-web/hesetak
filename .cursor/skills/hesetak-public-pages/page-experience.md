# حصتك — Page experience by target

Use this when building or redesigning a public page.  
**Rule:** same shell & visual system; **different job and emotional pitch** per target.

Product loop: تصفح → مسار → معلم → حجز → تقرير → محفظة.

---

## How to apply

1. Pick the page row below.  
2. Write for **Primary target** first; secondary only as a side door.  
3. One primary CTA above the fold.  
4. Proof near the CTA (معتمد / منهج / رأي ولي أمر).  
5. End with a clear next step into the loop.

---

## `/` — الهوم

| | |
|--|--|
| **Primary** | ولي أمر يكتشف المنصة + طالب يبحث بسرعة |
| **Job** | اختيار مسار (فردي / منهج / كورس) أو الدخول لدليل المعلمين |
| **Feeling** | ثقة خليجية، وضوح، جاهزية للحجز |
| **Above fold** | Hero shop: عنوان فيه البراند + ابحث عن معلم + انشاء حساب |
| **Body** | Mosaic مسارات → معلمون رائجون → باقات → آراء أولياء |
| **Avoid** | قصة فروع، teacher-PD كهوية وحيدة، أقسام زينة بلا CTA |

## `/instructors` — دليل المعلمين

| | |

## `/curricula` — المناهج الرسمية

| | |
|--|--|
| **Primary** | ولي أمر يعرف دولة/مرحلة ابنه |
| **Job** | اختيار منهج رسمي ثم الدخول لدليل المعلمين / الباقات |
| **Feeling** | مركز مسار عملي (مش كتالوج وهمي لوحدات المنهج) |
| **Above fold** | عنوان فيه البراند + عدد معلمين + CTAs: معلمون · باقات · كورسات |
| **Body** | أنواع المناهج الخليجية (روابط بحث) → مراحل → مواد شائعة → كيف يعمل → فرق منهج/كورس |
| **CTA** | كل بطاقة → `/instructors?q=` أو `?skill=` |
| **Avoid** | عرض AcademicYear للتطوير المهني كمناهج طلاب؛ وعد بكتالوج وحدات غير موجود |

## `/courses` — الكورسات المستقلة

| | |
|--|--|
| **Primary** | ولي أمر/طالب يريد مهارة أو اختبار أو قرآن خارج المنهج |
| **Job** | تصفح كورسات `AdvancedCourse` النشطة والانتقال لتفصيل/اشتراك |
| **Feeling** | كتالوج كثيف مثل دليل المعلمين؛ فرق واضح عن المناهج والفردي |
| **Above fold** | عنوان فيه البراند + عدد كورسات + شريط بحث/تصنيف/ترتيب |
| **Body** | شبكة بطاقات كورس (صورة · تصنيف · معلم · دروس · سعر · استكشف) → فرق المسارات |
| **CTA** | لكل بطاقة: استكشف الكورس → `public.course.show` |
| **Avoid** | تبويب معلمين/مجموعات؛ خلط مع `/instructors` أو `/curricula`؛ نصوص وظائف ألمانيا |

## `/course/{id}` — تفصيل كورس

| | |
|--|--|
| **Primary** | ولي أمر/طالب قرر الاشتراك أو يقارن بسرعة |
| **Job** | فهم القيمة في ثوانٍ ثم إتمام شراء/اشتراك بأقل خطوات |
| **Feeling** | صفحة قرار سريعة: سعر واضح + CTA واحد + مسار 3 خطوات |
| **Above fold** | وسائط + عنوان + سعر + اشترِ الآن (لوحة لاصقة ديسكتوب / شريط سفلي موبايل) |
| **Body** | عن الكورس · ماذا ستتعلم · تفاصيل · كورسات ذات صلة |
| **CTA** | ضيف: تسجيل→checkout · مسجّل: checkout/مجانًا · مشترك: ابدأ التعلّم |
| **Avoid** | Sana/Glottical styles؛ تشتيت مسارات جماعية؛ أكثر من CTA أساسي |
