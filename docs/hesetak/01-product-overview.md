## التعريف

**حصتك** منصة تعليمية دولية متخصصة في الدروس الخصوصية أونلاين:

1. **دروس خصوصية مباشرة أونلاين (فردي 1:1)** — الموديل الأساسي  
2. **مسار المناهج الدراسية الرسمية** — مطابقة نوع المنهج/المرحلة (من الدليل؛ لا تُخلط مع «حضور» في كل دولة)  
3. **مسار الكورسات المستقلة** — قدرات/تحصيلي، قرآن، لغات، مهارات، دورات أولياء أمور، تطوير مهني كمساق اختياري  

**حضور معلن:** الولايات المتحدة · مصر · السعودية.  
**رؤية:** الأولى والأكثر موثوقية للطلاب في دول الخليج ومصر.  
**المعلمون:** معتمدون؛ اختيار/تغيير المعلم بسهولة.

## شارات الدليل

| شارة | المعنى | البناء |
|------|--------|--------|
| AI | دعم قرار + مراجعة بشرية | مسموح بشروط |
| جديد | يخدم الأونلاين الفردي | ضمن النطاق |
| **مرجعي** | فروع / جماعي كمنتج أساسي / HR / مخزون / ويكي… | **لا تبنِ** |

الجزء الثامن من الدليل = مرجعي بالكامل.

## الحلقات الأساسية

### طالب / ولي أمر
تصفح → مسار (فردي / منهج / كورس) → مطابقة معلم (مرحلة + مادة + نوع منهج) → حجز بتوقيت محلي → حصة → تقييم إلزامي + تقرير معلم → محفظة/فواتير → شهادات.

### معلم
تقديم → فرز → مقابلة تقنية → اعتماد → تأهيل إلزامي → توافر → حصص → تقرير إلزامي قبل الأجر → محفظة مستحقات.

### المال
الطالب يدفع مقدمًا (باقة/محفظة) → المنصة تحوّل للمعلم شهريًا بعد العمولة → سجل دائم غير قابل للتعديل المباشر.

## أدوار داخل النطاق

زائر · طالب/ولي أمر · ولي أمر (ربط أبناء) · معلم قيد المراجعة · معلم معتمد · محاسب · توظيف · علاقات عملاء · مشرف أكاديمي · مدير عام.

**خارج النطاق:** مدير فرع وأدوار مراكز فعلية.

## قواعد منتج صارمة

1. الصلاحية عند التنفيذ لا عند إخفاء الزر فقط.  
2. تبديل المعلم بلا تكلفة/قيود على رصيد المحفظة.  
3. الحصة مكتملة ماليًا فقط بعد تقرير المعلم.  
4. مطابقة ثلاثية: مرحلة + مادة + نوع منهج.  
5. تأكيد الدفع من webhook البوابة فقط.  
6. مخرجات AI تبدأ `pending_review`.  
7. لا ميزات الجزء الثامن المرجعي.

## هوية بصرية (الدليل)

كحلي أساسي + ذهبي/برتقالي للحجز والشراء + أبيض/رمادي. RTL. جوال أولًا للطلاب وأولياء الأمور.

واجهة الكود الحالية العامة قد تستخدم `mc-*` (MyCourses) — الـ CX يجب أن يخدم منتج حصتك لا «تطوير مهني للمعلمين فقط».
