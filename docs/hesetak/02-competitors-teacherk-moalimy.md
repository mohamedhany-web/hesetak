# 02 — دراسة منافسين: Teacherk + معلمي

تاريخ الدراسة: 2026-09-12  
المواقع: [teacherk.com](https://www.teacherk.com/) · [moalimy.com](https://moalimy.com/)  
الغرض: مرجع CX/IA لبناء صفحات حصتك العامة (نموذج قريب من طلب العميل: دروس خصوصية أونلاين).

---

## 1) لماذا هذان الموقعان؟

كلاهما سوق خليجي/عربي لـ **معلم خصوصي أونلاين ↔ طالب/ولي أمر** مع باقات ودفع مسبق ومسارات معلم منفصلة — نفس قلب موديل حصتك (المسار 1)، بدون عمق «مناهج رسمية متعددة الدول + كورسات مستقلة LMS» الذي يميّز الدليل.

| المحور | Teacherk | معلمي | حصتك |
|--------|----------|--------|------|
| حصة 1:1 أونلاين | نعم | نعم | نعم (أساسي) |
| جمهور طالب/ولي | نعم | نعم + تقييمات أولياء واضحة | نعم + ربط أبناء |
| لاندنج معلم | `/for-teachers` | تسجيل معلم + FAQ معلم | نعم |
| باقات / رصيد | محفظة ساعات بلا انتهاء | باقة حسب المادة (8/2/مستعجلة) | محفظة + باقات |
| تبديل معلم | حر | حر أي وقت | بلا تكلفة على الرصيد |
| تقرير حصة قبل الأجر | غير ظاهر بقوة | إلزامي صراحة | إلزامي (الدليل) |
| قدرات/تحصيلي/قرآن | نعم | قياس + قرآن + تأسيس | ضمن كورسات/مسارات |
| مناهج خليجية + LMS كورسات | شبه غائب | جزئي (دولي/جامعة) | **تميز حصتك** |
| AI | غير بارز | مدرب قدرات ذكي | AI + مراجعة بشرية |

## 2) Teacherk — تنظيم كامل

### 2.1 التنقل (Nav)

|------|---------|

فوتر: نفس الروابط + سياسة الخصوصية + شروط الاستخدام + سوشيال + **ترخيص المركز الوطني للتعليم الإلكتروني** (رقم تأهيل ظاهر) + كوكيز + واتساب عائم.

### 2.2 خريطة الصفحات المكتشفة

| المسار | الغرض |
|--------|--------|
| `/` | هوم تسويقي كامل |
| `/for-students` | لاندنج طالب (مراحل + باقات + FAQ + شهادات) |
| `/for-teachers` | لاندنج معلم (مزايا + خطوات انضمام + أدوات + FAQ) |
| `/packages` | باقات الساعات + كيف تستخدم الرصيد + FAQ مالي |
| `/contact` | تواصل |
| `/login` | دخول |
| `/register/student` | تسجيل طالب |
| `/privacy` `/terms` `/cookies` | سياسات |
| روابط مرحلة/مادة من الـ accordion | دخول مسار حجز حسب الصف |

ملاحظة: `/students` و `/teachers` رجعا 404 — الدليل الفعلي للمعلمين مدمج في الهوم/مودالات وليس مسار `/teachers` عام ظاهر بهذا الاسم.

### 2.3 ترتيب أقسام الهوم (IA)

1. **Hero:** عنوان عن معلمين خصوصيين لكل المراحل + قدرات وتحصيلي · CTA مزدوج · إحصائيات (معلمون 250+ / جلسات 2K+)  
2. **كيف تعمل:** اختر المادة → اختر معلمك → احجز وابدأ  
3. **حلول لكل المراحل (Accordion):**  
   - 1 ابتدائي (صف 1–6 + مواد)  
   - 2 متوسط  
   - 3 ثانوي  
   - 4 قدرات (تأسيس/مراجعة لفظي وكمي)  
   - 5 تحصيلي (مواد)  
   - 6 تأسيس إنجليزي  
   - 7 تأسيس عربي  
   - 8 تحفيظ قرآن  
4. **باقات ساعات** (بداية 40/4س · أساسي 80/8س · متقدم 120/12س) + رابط تصفّح الباقات  
5. **أفضل المعلمين:** بطاقات + مودال تفاصيل  
6. **ثقة:** معلمون مؤهلون · حجز سريع · مواعيد مرنة  
7. **شهادات:** معلم / طالبة / ولي أمر  
8. **CTA نهائي:** ابحث عن معلم · انضم كمعلم  

### 2.4 بطاقة / ملف المعلم (من المودال)

- الاسم، التخصص، نبذة  
- عدد دروس / طلاب  
- **سعر الساعة**  
- سنوات خبرة / تاريخ انضمام  
- فيديو تعريفي  
- التقييم  
- مؤهلات تعليمية + نص «عنّي»

### 2.5 موديل الباقات (Teacherk)

- شراء **رصيد ساعات**  
- صالح مع **أي معلّم**  
- يُخصم تلقائيًا عند الحجز  
- **صلاحية مفتوحة بلا انتهاء**  
- صفحة `/packages` تضيف باقة فصل (مثال: 50 ساعة / 475)  
- FAQ: لا انتهاء رصيد · إلغاء الطالب لا يُرجع · إلغاء/غياب المعلم يُرجع الساعات · سعر موحّد داخل الباقة · ضريبة ظاهرة  

### 2.6 لاندنج الطلاب `/for-students`

- Hero + احجز درسًا  
- نفس كتالوج المراحل  
- باقات  
- فوائد أكاديمية (أداء / أساس / امتحانات)  
- FAQ: مدة الجلسة · أونلاين 100% · الحجز فوري بلا انتظار موافقة معلم · تجربة أكثر من مدرّس  
- شهادات + CTA  

### 2.7 لاندنج المعلمين `/for-teachers`

- Hero: انضمّ كمعلم  
- مزايا: طلاب جاهزون · جدول مرن · زد دخلك (تحديد سعر الساعة)  
- مجالات التدريس حسب المراحل  
- خطوات: حساب → ملف كامل → استقبال طلبات  
- أدوات: لوحة · جدول · أرباح · تقييمات · إشعارات  
- FAQ: صرف مستحقات لمحفظة ثم بنك · تحديد السعر · الظهور في القوائم · وضع إجازة  
- شهادات معلمين + CTA  

### 2.8 نبرة Teacherk (ما ينجح)

- بسيط، أقسام قليلة، CTA واضح  
- فصل جمهور (طالب vs معلم) بصفحات كاملة  
- Accordion مراحل يقلل الزحمة  
- ثقة تنظيمية (NELC) ظاهرة  
- واتساب دعم  

### 2.9 ضعف Teacherk أمام حصتك

- لا مسار «منهج رسمي حسب الدولة» واضح  
- لا كتالوج كورسات مستقلة / LMS  
- دليل معلمين كصفحة فهرس مستقلة غير واضح من الـ URL  
- بيانات معلمين أحيانًا فارغة (0 دروس / 0 تقييم) تضعف الثقة

### 3.2 خريطة الصفحات المكتشفة

### 3.3 ترتيب أقسام الهوم

1. Hero: «المنصة الأولى لتوفير معلمين… التدريس الخاص عن بعد»  
2. **اختر الباقة المناسبة** — فلاتر مراحل: ابتدائي · متوسط · ثانوي · دولي · جامعة · قياس · تطوير مهارات + مواد (تأسيس أطفال، قرآن، رياضيات، علوم، عربي، إنجليزي، اجتماعيات…)  
3. لكل باقة مادة: وصف الحصة (60 دقيقة، متابعة، واجبات…) + **3 أسعار ظاهرة**  
4. لماذا معلمي الأفضل: سعر · إشراف · وقت/تبديل معلم · التدريس · الجودة  
5. بلوك AI قدرات  
6. تقييمات عملاء (غالبًا أولياء أمور)  
7. خطوات التسجيل: حساب → باقة ومعلم → سداد وبدء  
8. فوائد الاستثمار في تعليم الأبناء  

### 3.4 تسعير ظاهر (ابتدائي كمثال على الهوم)

| العرض | تقريب السعر |
|-------|-------------|
| 8 حصص | ~56 ر.س / حصة |
| 2 حصص | ~64 ر.س / حصة |
| حصة مستعجلة اليوم | ~76 ر.س / حصة |

### 3.5 رحلة الطالب (من `/how-to-work` + FAQ)

1. إنشاء حساب وتفعيله  
2. اختيار باقة أو أكثر وإكمال الشراء  
3. البحث عن معلم/معلمة + اختيار أوقات  
4. حضور الدروس عن بعد  
5. مراجعة **تقرير الحصة**  
6. إمكانية تغيير المعلم في أي وقت · تقييم المعلم · الرجوع للحصص السابقة  

### 3.6 رحلة المعلم (من `/how-to-work` + FAQ)

1. تجهيز أجهزة (كمبيوتر، كاميرا، مايك، سبورة، إنترنت، مكان هادئ) — المنصة لا توفر الجهاز  
2. إنشاء حساب + بيانات ومرفقات لفريق المنصة  
3. تحديد ساعات العمل الأسبوعية بمرونة  
4. استقبال حجوزات + إشعار  
5. بعد الحصة: **إدخال التقرير = اكتمال الحصة واحتساب الأجر**  
6. تقييم الطلاب · تحويل مستحقات **شهريًا** للحساب البنكي  
7. تقييم منخفض متكرر → إيقاف حساب (سياسة جودة)

### 3.7 نبرة معلمي (ما ينجح)

- **باقة أولًا** واضحة للولي أمر الذي يعرف المادة  
- أسعار ظاهرة بدون تسجيل  
- FAQ و How-to بتبويب جمهورين  
- إشراف أكاديمي كرسالة ثقة  
- حصة مستعجلة = حاجة واقعية  
- مسوّق / هدايا / مدونة = نمو وتسويق  

### 3.8 ضعف معلمي أمام حصتك / UX

- واجهة أقدم وأثقل بصريًا من Teacherk  
- الهوم طويل جدًا (تكرار بطاقات باقات)  
- أقل وضوحًا لمسار «اكتشف معلمًا أولًا»  
- لا تمييز قوي لمناهج دول متعددة كمنتج أول

## 5) ما نأخذ / ما نترك / ما نزيد (حصتك)

### نأخذ من Teacherk
- Nav بسيط + لاندنجات `/for-students` و `/for-teachers`  
- Accordion مراحل ومواد  
- باقات ساعات بلا انتهاء صالحة مع أي معلم  
- بطاقة معلم: فيديو + سعر + مؤهلات  
- شارة ترخيص إلكتروني ظاهرة  
- واتساب عائم  

### نأخذ من معلمي
- أسعار ظاهرة قبل التسجيل  
- How-to + FAQ بتبويبين  
- رسالة «تقرير الحصة إلزامي»  
- حصة مستعجلة (إن وافق المنتج)  
- فيديوهات إرشادية / دليل مقررات  
- تقييمات أولياء أمور صريحة  

### نترك / لا ننسخ أعمى
- سلة متجر ثقيلة إن عارضت محفظة الدليل  
- مسار مسوّق إلا بقرار منتج  
- أي UX فروع/حضور جماعي (مرجعي)  

### نزيد (تميز حصتك من الدليل)
- مدخل **مناهج رسمية حسب الدولة**  
- مدخل **كورسات مستقلة**  
- مطابقة معلم: مرحلة + مادة + **نوع منهج**  
- حساب ولي أمر وربط أبناء  
- شهادات تحقق عام  
- AI باقتراح + مراجعة بشرية (ليست بديل المعلم)
