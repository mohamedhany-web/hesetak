## مبدأ التنظيم

الهوم يجيب على سؤال واحد للزائر:  
**«عايز حصة فردية، ولا منهج رسمي، ولا كورس مستقل؟»**

ثم يوجّه لمسار واضح — بدون قصص مرجعية (فروع/جماعي).

```
زائر
 ├─ حصة فردية 1:1  → دليل معلمين / باقات ساعات → حجز
 ├─ منهج رسمي      → كتالوج مناهج (دولة+مرحلة+مادة) → تسجيل/حجز
 ├─ كورس مستقل     → كتالوج كورسات → اشتراك
 ├─ أنا معلم        → لاندنج معلمين → تقديم
 └─ ثقة/دعم         → كيف نعمل · FAQ · تواصل · سياسات
```

## هيكل الهوم المقترح (أقسام)

1. **Hero واحد:** علامة حصتك + جملة قيمة (معلمون معتمدون · حصص فردية · مناهج · كورسات) + CTA أساسي واحد قوي + ثانوي  
   - أساسي مقترح: «ابحث عن معلم» أو «ابدأ الآن»  
   - ثانوي: «انضم كمعلم»  
2. **ثلاث بطاقات مسار (ليست بطاقات زينة):** فردي · مناهج · كورسات  
3. **كيف تعمل في 3 خطوات** (على نمط Teacherk)  
4. **مراحل ومواد (Accordion أو شبكة)** — ابتدائي… + قدرات/تحصيلي/قرآن كمسارات  
5. **باقات ساعات** (منطق Teacherk: أي معلم، بلا انتهاء)  
6. **معلمون مميزون** → رابط الدليل الكامل  
7. **ثقة:** اعتماد معلمين · ترخيص إن وُجد · تقييمات أولياء  
8. **شهادات قصيرة** (طالب / ولي / معلم)  
9. **CTA نهائي**

تجنّب تكديس إحصائيات كثيرة + جداول + بروموهات في أول شاشة (قواعد التصميم العامة للمشروع).

## فلترة دليل المعلمين (حرج للمنتج)

يجب أن تدعم الواجهة على الأقل:

1. المرحلة الدراسية  
2. المادة  
3. **نوع المنهج** (سعودي / قطري / …)  

ثم اختياري: الجنس، السعر، التقييم، توافر اليوم، لغة الشرح.

بطاقة المعلم تعرض: صورة · اسم · مواد/مراحل · تقييم · سعر أو «ضمن الباقة» · شارة معتمد · فيديو إن وُجد · CTA «احجز» / «تعرّف».

---

## تدفقان للاكتشاف (ادعم الاثنين)

### A — معلم أولًا (Teacherk-like)
مراحل → قائمة معلمين → ملف → اختيار موعد → دفع/خصم محفظة → حجز

### B — باقة أولًا (Moalimy-like)
باقة ساعات أو باقة مادة → اختيار معلم → موعد → حجز

حصتك تفضّل محفظة ساعات عامة + مسارات مناهج/كورسات كمنتجات منفصلة.

## علاقة بالـ Routes الحالية في الكود

عند التنفيذ: طابق المقترح مع `routes/web.php` والـ Blade الحالية (`mc-*`).  
أي مسار جديد يُضاف صراحة؛ أي مسار قديم بقصة «تطوير مهني فقط» يُعاد صياغة نصوصه لا حذف أعمى للكود.
