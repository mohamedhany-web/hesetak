# 04 — موجزات الصفحات العامة (Page Briefs)

استخدم هذا الملف عند تصميم أو بناء كل صفحة.  
قاعدة CX: من الزائر؟ ماذا يريد هنا؟ CTA واحد أساسي؟ إثبات ثقة؟ الخطوة التالية؟

---

## `/` — الهوم

| | |
|--|--|
| **الزائر** | طالب أو ولي أمر يكتشف المنصة؛ معلم محتمل كثانوي |
| **الهدف** | اختيار مسار: فردي / منهج / كورس أو الدخول لدليل المعلمين |
| **CTA أساسي** | ابحث عن معلم |
| **CTA ثانوي** | انشاء حساب |
| **أقسام (حيّ)** | Hero shop كامل العرض → mosaic 3 مسارات → معلمون رائجون → باقات → آراء أولياء → فوتر |
| **ممنوع** | قصة فروع، بطاقات زينة بلا فعل، تسويق teacher-PD كهوية وحيدة، clutter في الهيرو |
| **مراجع** | skill `hesetak-public-pages` · `visual-system.md` · `page-experience.md` |

| | |
|--|--|

## `/for-teachers` — للمعلمين

| | |
|--|--|
| **الزائر** | معلم يفكّر بالانضمام |
| **الهدف** | تسجيل تقديم / فهم الاعتماد والدخل |
| **CTA** | قدّم الآن / سجّل كمعلم |

| **ملاحظة** | لا تُظهر اعتمادًا فوريًا كاذبًا — الدليل يشترط مراجعة أكاديمية+تقنية |

## `/how-it-works` — كيف تعمل المنصة

| | |
|--|--|
| **النمط** | تبويبان مثل معلمي: طالب/ولي \| معلم |
| **طالب** | حساب → اختيار مسار/باقة → معلم → حصة → تقرير وتقييم |
| **معلم** | تقديم → اعتماد → توافر → حصص → تقرير → مستحقات شهرية |

---

## `/faq` — الأسئلة الشائعة

| | |
|--|--|
| **النمط** | تبويب طالب \| معلم (معلمي) |
| **محتوى طالب** | باقات متعددة، تبديل معلم، إلغاء حصة، تقييم، اختبارات تدريبية إن وُجدت |
| **محتوى معلم** | الدخل، الأجهزة، التقييم المنخفض، موعد التحويل، تأجيل، إلزامية التقرير |

## Checklist قبل اعتبار الصفحة «منتهية»

- [ ] CX لطالب/ولي (أو معلم في صفحته) وفق المنتج  
- [ ] لا ميزات مرجعية  
- [ ] CTA واحد أساسي واضح  
- [ ] RTL + جوال  
- [ ] نصوص حصتك (لا Teacherk/معلمي/Glottical كعلامة)  
- [ ] ar + en إن كانت الصفحة عامة  
- [ ] متوافق مع `hesetak-public-pages` و `mc-*`
