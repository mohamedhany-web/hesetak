## د) قواعد عند التعارض

| تعارض | القرار |
|-------|--------|
| شكل `mc-*` الحالي vs كحلي/ذهبي الدليل | أبقِ النظام العامل؛ حدّث التوكنات بقرار صريح لا بكسر الصفحات |
| سلة معلمي vs محفظة الدليل | فضّل المحفظة/الباقات كرصيد |
| حجز فوري Teacherk vs قواعد توافر/موافقة | اتبع `operations` ورحلات الدليل |
| أي طلب فروع/جماعي | `exclude-reference` → رفض |
